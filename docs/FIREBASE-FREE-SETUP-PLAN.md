## 3. الأمان (بند 3 و4 من طلبك) — **مُنفَّذ ومُختبَر**

`firestore.rules` تفرض:
- **لا وصول بدون عضوية نشطة**: مجرد امتلاك حساب Google لا يكفي.
- **المالك فقط** يعدّل وثيقة المحل، و`ownerUid` **غير قابل للتغيير أو الحذف**.
- **لا يمكن إنشاء عضوية بدور `owner`** ولا ترقية عضو إليه — حتى من المالك نفسه عبر الطلب.
- **عضوية المالك** لا تُعدّل ولا تُحذف.
- **سجل التدقيق** غير قابل للتعديل أو الحذف لأي أحد (حتى المالك).
- كل صلاحية من المصفوفة تُفحص عند كل عملية (view_customers / add_customer / edit_transaction …إلخ).
- أي مسار خارج `shops/main` **ممنوع تمامًا**.

### البوابة: `tests/verify-firestore-rules.ts` — 11 مجموعة / 35 تأكيدًا — **0 فاشل**
شُغّلت على **محاكي Firestore الحقيقي** (Google Rules Engine)، ومنها:
غير المسجّل يُرفض · الغريب بلا عضوية يُرفض · الموظف المعطّل يُرفض حتى مع صلاحيات · المالك يقرأ/يكتب · صاحب `view_customers` يقرأ ولا يكتب · صاحب `add_customer` يضيف ولا يعدّل · تعديل/حذف سجل التدقيق مرفوض للجميع · إنشاء/ترقية إلى owner مرفوضة · تغيير ownerUid مرفوض · حذف وثيقة المحل مرفوض.

## 5. الخطوات المطلوبة منك الآن (مرة واحدة — مجانية، بلا بطاقة)

1. <https://console.firebase.google.com> → **Add project** → اسم `ah2-shop` → أوقف Analytics → **Create**.
2. تأكد أن الخطة **Spark** (لا تضغط Upgrade أبدًا).
3. **Authentication** → Get started → **Google** → Enable → اختر بريدك → Save.
4. **Firestore Database** → Create database → **Production mode** → `me-central1` → Create.
5. **Project settings ⚙ → Your apps → Web `</>`** → اسم `AH2 Web` → Register → انسخ قيم `firebaseConfig` الستة.
6. **Firestore → Rules** → انسخ محتوى `firestore.rules` من هذا المستودع → Publish.
7. سجّل دخولًا تجريبيًا بزر Google (بعد المرحلة التالية) أو من **Authentication → Users** لمعرفة **UID** الخاص بك، ثم أنشئ يدويًا وثيقتين:
   - `shops/main` → الحقول: `name` (اسم المحل) · `ownerUid` = UID الخاص بك · `createdAt`
   - `shops/main/members/{UID}` → `uid` · `name` · `role` = `owner` · `status` = `active` · `permissions` = `[]`
8. أرسل لي قيم `firebaseConfig` الستة (ليست أسرارًا) — وسأضعها في `.env.local` المستثنى من git.

**لا حاجة لأي مفتاح خدمة (Service Account) ولا أي بطاقة.**
